# ProjDock contributor rules

## Goal

Users group browser tabs, folders, files and links into a "project" and reopen everything with one click.

## Development constraints

- Keep code simple.
- Use plain JavaScript; do not use TypeScript.
- Keep dependencies minimal.
- The browser extension uses Chrome Manifest V3.
- The desktop app uses Electron.
- Do not add features that were not requested.

## Completion requirements

Before finishing any task, list the files changed and explain how to test the result manually.
